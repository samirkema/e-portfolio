## English

### What is HowMany?

HowMany is a full-stack mobile and web application to log and share your experiences — films, restaurants, travel, music, and more — with your friends. Each entry gets an overall rating plus custom criteria, photos, and a visibility setting.

### Features

- **Authentication** — sign up / log in with bcrypt-hashed passwords
- **Post an experience** — category, title, overall star rating + technical criteria, up to 4 photos
- **Visibility control** — Public / Friends / Private, changeable at any time
- **Global feed** — all public notes from every user
- **Friends feed** — notes from friends and friends-of-friends
- **Profile** — editable profile picture, full journal (public + friends + private entries)
- **Friend system** — send, accept, and remove friend requests
- **Public profiles** — browse another user's public experiences

### Tech stack

| Layer | Tech |
|---|---|
| Mobile app | React Native (Expo) + TypeScript |
| Web | React Native Web — deployed on Vercel |
| Server | Node.js + Express — deployed on Render |
| Database | PostgreSQL (Supabase) |

## Français

### Qu'est-ce que HowMany ?

HowMany est une application mobile et web full-stack pour consigner et partager vos expériences — films, restaurants, voyages, musique, etc. — avec vos amis. Chaque entrée reçoit une note globale, des critères personnalisés, des photos et un réglage de visibilité.

### Fonctionnalités

- **Authentification** — inscription / connexion avec mots de passe hachés (bcrypt)
- **Publier une expérience** — catégorie, titre, note globale en étoiles + critères techniques, jusqu'à 4 photos
- **Contrôle de la visibilité** — Public / Amis / Privé, modifiable à tout moment
- **Fil global** — toutes les notes publiques de tous les utilisateurs
- **Fil des amis** — notes des amis et des amis d'amis
- **Profil** — photo de profil modifiable, journal complet (entrées publiques, amis et privées)
- **Système d'amis** — envoyer, accepter et supprimer des demandes d'amis
- **Profils publics** — parcourir les expériences publiques d'un autre utilisateur

## 中文

### HowMany 是什么？

HowMany 是一款全栈的手机和网页应用，用来记录并与朋友分享你的体验——电影、餐厅、旅行、音乐等。每条记录都包含总体评分、自定义评价维度、照片以及可见性设置。

### 功能

- **身份验证** — 注册 / 登录，密码使用 bcrypt 哈希存储
- **发布体验** — 分类、标题、星级总评 + 细项评分，最多 4 张照片
- **可见性控制** — 公开 / 好友 / 私密，可随时更改
- **全局动态** — 所有用户的公开笔记
- **好友动态** — 好友以及好友的好友的笔记
- **个人主页** — 可更换头像，完整日志（公开、好友可见和私密记录）
- **好友系统** — 发送、接受和删除好友请求
- **公开主页** — 浏览其他用户的公开体验

### 技术栈

| 层级 | 技术 |
|---|---|
| 手机应用 | React Native (Expo) + TypeScript |
| 网页 | React Native Web — 部署在 Vercel |
| 服务器 | Node.js + Express — 部署在 Render |
| 数据库 | PostgreSQL (Supabase) |
