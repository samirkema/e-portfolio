## What is HowMany?

HowMany is a full-stack web and mobile application that lets users track, log, and share personal experiences — how many times they've done something, where, and with whom. Users can explore other people's experiences, follow others, and build a personal history of their activities.

## Features

- **User authentication** — sign in / sign up with account management
- **Experience logging** — create and track personal entries with metadata
- **Explore feed** — discover and browse other users' experiences
- **Responsive design** — accessible from any device

## Tech stack

- **Frontend**: React Native (Expo Router) deployed on Vercel
- **Backend**: Node.js server
- **Deployment**: Vercel
